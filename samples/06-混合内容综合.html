一、概述

本指南介绍如何接入乐享知识库 API。接入前请准备 API Token 和 知识库 ID。详见 官方文档。

提示：所有接口均需在请求头携带 Authorization: Bearer {token}。

四、接口列表

方法路径说明
GET/kb/entries获取条目列表
POST/kb/entries创建条目
POST/kb/entries/{id}/content导入内容（支持 html）

五、调用步骤

  1. 获取 API Token
  2. 调用鉴权接口验证
    1. 请求头携带 Bearer Token
    2. 检查返回状态码是否为 200
  3. 调用业务接口获取/写入数据
  4. 处理响应并落库

六、代码示例（Python）

import requests

headers = {"Authorization": "Bearer YOUR_TOKEN"}
r = requests.get(
    "https://lxapi.lexiangla.com/cgi-bin/v1/kb/entries",
    headers=headers
)
print(r.json())
